# Cerebro DNano website: design handoff (new design only)

Paste ANTIGRAVITY-KICKOFF.md into Antigravity first, then follow HANDOFF.md: route map, rules, components, mobile rules, interactions, open items and the build prompts for Antigravity.

- design/                         32 approved pages plus the shared header and footer, one file per route
- design/_mobile/                 7 mobile designs at 390px, one per template
- design/_reference/              style library and the components and states sheet (reference, no pages to build)
- brand/                          logo mark and wordmark as SVG, dark and white
- tokens/                         design tokens (CSS and JSON)
- reference/page-builder/         source that generated every page (component inventory)
- reference/site-hierarchy.md     every route and its design file
